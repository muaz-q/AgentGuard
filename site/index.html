How It Works

Three steps. No API key.

01

Install AgentGuard

One pip command. No API key and no sign-up: AgentGuard never calls a model or runs your code.

pip install agentguard-lint
02

Navigate to your project

Point your terminal at any Python project directory containing agent code.

cd your_project
03

See the cost risks

Each finding comes with a file, a line, a severity and a fix, plus a cost range per run.

agentguard .
Installation

One command to get started.

No API key, no sign-up, no runtime dependencies. Python 3.9 or newer.

$ pip install agentguard-lint
If agentguard isn't found (pip's scripts folder is not on PATH), run:
$ python -m agentguard .
Usage

Run it. That's it.

Run it from your project folder. It scans every Python file in it and its subfolders, skipping virtual environments and hidden folders.

⭐ Recommended — if PATH is configured
$ agentguard .
Fallback — works everywhere without PATH
$ python -m agentguard .
// WHAT DOES "." MEAN?
"." = current folder. AgentGuard will recursively scan:
→ All .py files in the current folder
→ All subfolders inside it, automatically
💡
TIP — Run from your project root.
python -m agentguard . crawls subfolders automatically, so running it from the root directory gives you full coverage in one pass. Running it from a subfolder only scans that subfolder and below.
Method Works Without PATH Recommended
agentguard . ❌ Needs PATH ⭐ Best
python -m agentguard . ✅ Yes Fallback
It refuses to scan a home folder or a whole drive, which is never one project.
What It Detects

Seven rules, each with a fix.

Every finding names the file, the line and the rule. Rule reference →

🔁

Uncapped agent loops

AG001. An LLM call in a loop that stops only when the model says so. Step counters, if step >= MAX: break, countdowns and retry helpers count as caps.

📈

Quadratic history growth

AG002. A conversation history that grows every turn and is re-sent in full. Trimming with messages[-k:] or summarising is recognised.

🌀

Nested loops and recursion

AG003 and AG005. Calls multiplied by nested loops, and functions that call a model and themselves with no depth parameter.

💸

Cost per run

Each call priced at the model named in the code, at 1, 10 and 100 loop iterations. Also flags missing max_tokens (AG006), one call per item (AG004) and uncached Anthropic prompts (AG007).

Why It Matters

Agent costs grow with the square of the turns.

An LLM API keeps no memory, so an agent re-sends the whole conversation on every turn. Turn 40 pays for the 39 turns before it. Pricing an agent as "number of calls × cost of one call" misses this completely.

In a measured 40-turn run on a local model, that naive estimate was 99% too low. AgentGuard, calibrated on the first two turns, was 11% low.

Run on 22 open-source agent projects, it found the pattern in OpenAI's own swarm library, whose turn limit defaults to infinity. How it was measured →
